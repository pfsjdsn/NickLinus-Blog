**方法一** 
Object.assign(target, …sources)
将一个或者多个源对象中所有可枚举的自有属性复制到目标对象，并返回修改后的目标对象

target——>目标对象
source——>源对象

[MDN文档-Object.assign](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Reference/Global_Objects/Object/assign) 

```js
let arr = [];
let obj = { name: "小明" };
arr.push(Object.assign({}, obj)); // 创建一个新对象并将其添加到数组中
console.log(arr); // [{name: "小明"}]

```
