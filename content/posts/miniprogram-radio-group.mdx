**.wxml文件** 

```html
<radio-group class="radio-group" bindchange="radioChange">
    <label class="radio">
        <radio value="1"/>
    </label>
    <label class="radio">
        <radio value="2"/>
    </label>
</radio-group>
```

**.js文件** 

```javascript
radioChange: function (e) {
	console.log(e.detail.value)
	console.log('radio发生change事件，携带value值为：', e.detail.value)
	
},
```
