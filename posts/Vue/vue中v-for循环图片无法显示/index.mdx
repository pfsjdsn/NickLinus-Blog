# Vue——vue中v-for循环图片无法显示

> 文章链接：https://blog.csdn.net/qq_43201350/article/details/110916382

**解决方法: 使用require调用路径** 

```
<div v-for="(item, index) in imgList" :key="index">
    <img :src="item">
</div>
```

```
<script>
export default {
  data() {
    return { 
      imgList:['require("../../assets/a.jpg")','require("../../assets/b.jpg")']
    };
  },
};
</script>
```
