## 1，使用parseInt()

```dart
var str ="4500元";
var num = parseInt(str);
alert(num);//4500
```

2，使用正则

```text
var s ="价格4500元";
var num= s.replace(/[^0-9]/ig,"");
alert(num);//4500
```
