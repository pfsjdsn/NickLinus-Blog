reduce() 方法接收一个函数作为累加器，数组中的每个值（从左到右）开始缩减，最终计算为一个值。

```js
let  arr = [1, 3, 5, 7,10]      
let max = arr.reduce((key1, key2) => {
return key1 = key1 > key2 ? key1 : key2
});
console.log(max)   // 10
```
