**解决方法: 使用require调用路径** 

```vue
<div v-for="(item, index) in imgList" :key="index">
    <img :src="item">
</div>
```

```vue
<script>
export default {
  data() {
    return { 
      imgList:['require("../../assets/a.jpg")','require("../../assets/b.jpg")']
    };
  },
};
</script>
```
