**wxml文件** 

```html
<view bindtap="selectDistrict" data-text="{{content}}" data-id="{{id}}">{{content}}</view>
```

**.js文件** 

```javascript
data: {
 content:'我是内容',
 id: 1
}
  selectDistrict: function (e) {
      console.log(e.currentTarget.dataset.id) // 1
      console.log(e.currentTarget.dataset.text) //我是内容
  },
```
