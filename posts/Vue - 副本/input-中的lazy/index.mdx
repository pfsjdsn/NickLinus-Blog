# Vue——input 中的lazy

> 文章链接：https://blog.csdn.net/qq_43201350/article/details/120398818

加入lazy后把searchKey变成change事件改变值

```vue
<input v-model.lazy="searchKey" type="text">
<h1>
    {{searchKey}}
</h1>

data() {
return {
searchKey: ''
}
}
```
