方式一：整齐排列

```js
let str = '<table>'
for (let i = 1; i <=9; i++) {
        str+= '<tr>'
    for (let j = 1; j <= i; j++) {
         str +=  '<td>' + j + '*' + i + '=' + i*j + '<td/>'
        console.log(str)
        
    }
    str += '</tr>'
    
}
str+='<table/>'
document.write(str)
```

方式二：不整齐排列

```js
for (var i = 1; i <= 9; i++) {
    for (var j = 1; j <= i; j++) {
      document.write(j + "*" + i + '=' + i * j + '&nbsp;&nbsp;&nbsp;')
      if (i == j) {
        document.write("<br/>")
      }

    }
  }
```
